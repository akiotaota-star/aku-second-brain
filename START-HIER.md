# Dein Second Brain auf dem Mac

Das Paket verbindet dein Content- und Business-Wissen mit einem Obsidian-Vault. Claude führt dich durch die Einrichtung und fragt die benötigten Materialien nacheinander ab.

## Start

1. Das [öffentliche Repository](https://github.com/akiotaota-star/aku-second-brain) öffnen. Zum Herunterladen brauchst du keine Einladung.
2. Über **Code → Download ZIP** herunterladen und in einem von dir gewählten Arbeitsordner entpacken; alternativ mit Git klonen. Wenn du nur das ZIP verwendest, benötigst du Git nicht zum Herunterladen.
3. Claude Code lokal auf deinem Mac mit dem entpackten Repository-Ordner als Projekt öffnen. Falls du die Terminal-Version nutzt: in diesen Ordner wechseln und `claude` starten. Falls Claude Code fehlt: [offizielle Einrichtung](https://code.claude.com/docs/en/setup).
4. In Claude Code **`/brain-setup`** eingeben. Falls der Befehl nicht angezeigt wird, die folgende Nachricht einfügen:

> Lies CLAUDE.md und .claude/skills/brain-setup/SKILL.md. Führe mich anhand docs/ONBOARDING.md Schritt für Schritt durch die Einrichtung meines Second Brain. Stelle jeweils nur die nächste Frage und warte auf meine Antwort. Sag mir genau, welche Dateien du jetzt brauchst und wo ich sie bereitstellen soll. Erfasse auch Google Drive, alle vorhandenen und bereits verwendeten Content-Skripte und meine Originalvideos. Behandle keine Videoanalyse als vollständig, bevor Sprache, Audio, Bild und Bewegung tatsächlich geprüft wurden.

## Was Claude mit dir einrichtet

Deinen Speicherort, Obsidian, die exakten YouTube-/Instagram-Accounts, ausgewählte Google-Drive-Ordner, dein Skriptarchiv, Originalvideos, verfügbare Analytics und Unterlagen zu Kali Society. Du musst dafür nicht vorher alles sortieren oder auf einmal hochladen. Claude sagt dir jeweils, was als Nächstes gebraucht wird, prüft die Lieferung und merkt sich offene Schritte.

Die Inhalte werden in deiner eigenen Ablage gespeichert, außerhalb des GitHub-Repositories. Kundeninformationen bleiben in einem getrennten privaten Bereich. Ein Drive-Link muss nicht öffentlich sein; Claude prüft einen vorhandenen Zugang oder erklärt dir, wie du die ausgewählten Dateien lokal bereitstellst.

Zunächst werden drei Videos als Pilot bearbeitet, danach der gesamte erfasste Bestand. Das Paket bereitet Sekundenprotokolle und Clips vor. Für die tatsächliche Beurteilung von Tonfall, Gestik und Editing wird beim Setup ein geeigneter Analyseweg eingerichtet; nur ein Transkript reicht dafür nicht. Claude erklärt dir auch, welche Inhalte dabei einen Modellanbieter erreichen würden.
